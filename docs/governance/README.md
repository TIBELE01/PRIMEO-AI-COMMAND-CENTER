# Gouvernance

Documentation des règles d'autonomie contrôlée des agents :

- les trois niveaux d'autorisation (1 autonome, 2 validation préalable du PDG, 3 intervention humaine) ;
- la liste des actions et leur niveau ;
- le circuit de validation (approuver, refuser, demander une modification) ;
- la traçabilité et le journal d'activité ;
- la gestion des secrets et le modèle de menaces (injection de prompt, escalade de privilèges).

Implémentation correspondante : `packages/security/`.

Détails : [`secrets.md`](./secrets.md) — gestion des variables d'environnement et des secrets.
