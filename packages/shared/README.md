# @primeo/shared

Socle commun, **sans aucune dépendance** vers les autres paquets.

| Dossier      | Contenu                                                                                |
| ------------ | -------------------------------------------------------------------------------------- |
| `types/`     | Types métier : directions, agents, missions, validations, rapports, indicateurs        |
| `constants/` | Constantes : statuts de mission, niveaux d'autorisation 1/2/3, priorités, périodicités |
| `schemas/`   | Schémas de validation (zod) partagés entre le frontend, l'API et les workers           |
| `utilities/` | Fonctions utilitaires pures (dates, formatage, identifiants…)                          |
