# @primeo/observability

Observabilité **technique** (à ne pas confondre avec le journal d'activité métier, géré par
`@primeo/governance/audit`).

| Dossier    | Rôle                                                        |
| ---------- | ----------------------------------------------------------- |
| `logger/`  | Logs structurés JSON, avec masquage automatique des secrets |
| `tracing/` | Corrélation des requêtes, tâches et appels aux modèles d'IA |
