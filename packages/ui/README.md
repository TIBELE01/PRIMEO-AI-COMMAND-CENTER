# @primeo/ui

Design system de Primeo, en React, utilisé par `apps/web`.

| Dossier          | Contenu                                                                     |
| ---------------- | --------------------------------------------------------------------------- |
| `design-system/` | Jetons de design : couleurs, typographie, espacements, rayons, thème sombre |
| `components/`    | Composants génériques : boutons, champs, tableaux, cartes, modales…         |
| `charts/`        | Graphiques des tableaux de bord et des indicateurs de performance           |

Les composants ne contiennent aucune logique métier ni appel réseau : ils reçoivent leurs données
en propriétés. Les jetons seront établis à partir de la charte graphique Primeo.
